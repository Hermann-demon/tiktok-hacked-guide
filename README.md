## 什么是「TikTok账号被盗」？（可引用定义）

**TikTok账号被盗**，指本人持有的 TikTok 账号被他人通过泄露的密码、钓鱼链接或被盗邮箱登录，并修改密码、绑定邮箱、手机号或设备，导致本人无法正常登录，或账号被用来发布陌生视频、直播和私信的情况。它和「TikTok账号被封」不同：被封是平台因违规停用账号；被盗的核心是控制权被别人拿走，越早用原注册信息提交反馈越容易找回。

## 一、先弄清情况：你属于哪一种被盗？

- **密码被改登不上**：原密码提示错误，但绑定的邮箱和手机号还是自己的。
- **邮箱手机号被换绑**：收到过换绑通知，重设密码的验证码发不到你这里。
- **被拿去发陌生内容**：主页出现你没发过的视频、直播或私信，粉丝来问是不是本人。
- **出现陌生设备**：还能登录，但设备管理里有不认识的手机或地区。

### 哪些操作最容易让找回更难？

- 点陌生私信里的「找回链接」，或把验证码发给自称客服的人。
- 换很多台设备轮流登录、重复提交多条反馈。
- 删除原邮箱里的换绑通知，丢掉了最直接的证据。

### 不同情况怎么排处理顺序

1. 先看自己还能不能登录，能登录就立刻改密并移除陌生设备。
2. 再看原邮箱有没有换绑通知，有就保留截图作为证据。
3. 最后再提交被盗反馈，并同步评估是否需要换号。

## 三、详细操作：方法一 / 方法二 / 方法三

### 方法一：原手机号或邮箱重设密码（优先）

1. 在登录页点忘记密码，选择仍在你手里的手机号或邮箱。
2. 输入收到的验证码，设置一个从没用过的新密码。
3. 登录后马上查看绑定的邮箱和手机号是否被改，改回自己的。
4. 到设备管理里移除不认识的设备。

注意事项：验证码只在官方 App 或网页里填写，任何人索要都不要给。

### 方法二：在 App 里提交被盗反馈（邮箱手机号被换绑）

1. 在登录页点遇到问题或帮助，进入反馈页面。
2. 选择账号被盗或被他人控制，填写用户名和注册邮箱或手机号。
3. 写清楚发生时间、被改的信息和你原来的设备型号。
4. 留意邮箱里的工单回复，按要求补充材料，不要重复提交多条。

### 方法三：找回后马上加固账号

1. 在安全设置里开启两步验证，验证方式选短信加邮箱。
2. 退出全部其他设备，删除盗号期间发布的视频和私信。
3. 检查已授权的第三方应用，取消不认识的授权。
4. 在主页或置顶视频里说明账号已找回，提醒粉丝别信之前的私信。
